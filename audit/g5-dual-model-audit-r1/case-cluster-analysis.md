## 对论文使用口径的含义

1. 视图级 κ/agreement 仅描述"两个模型在这 30 份视图上的一致性",不支持任何任务级推断。
2. 若论文需要任务级结论,必须回到 3 个 evidence run 的任务定义另行设计抽样,本轮不提供。
3. 按 run 的分歧率(80%/69%/100%)进一步表明分歧由**压缩机制的系统性行为 × 模型敏感度**驱动,
   而非随机噪声:同一 run 内 A 的判定高度一致(2e2b 全 FAIL),B 也高度一致(2e2b 全 PASS)。
